# 综合项目模拟房源网页

本目录用于“综合项目：某市在售房源数据可视化分析”的第一阶段网页数据获取。

- `index.html`：可直接部署到云服务器的模拟房地产信息门户网页。
- 数据来源：`table_raw/final_house_portal_raw.csv`。
- 数据量：5036 条。
- 字段：产权、关注、区域、单价、小区、年限、总价/万元、户型、房屋编码、挂牌时间、朝向、楼层、装修情况、面积。

教学处理说明：

- 保留原始房源字段，方便学生从网页表格抓取后再派生建模字段。
- 加入少量重复房屋编码、缺失区域/小区、格式不统一、极端面积/单价样本。
- 学生不需要知道这些处理细节，可在第一阶段通过清洗统计自行发现。
